# CS614 Final Term Practice (offline)

`CS614-Final-Term-Practice.html` is a single, self-contained study app for the VU **CS614 Data Warehousing** final term. Download the one file and open it in any browser; it needs no internet and no other files.

What it contains (compiled from the five past-paper PDFs):

- **231 MCQs** with the correct option marked (Junaid solved MCQs, lectures 23–45; Waqar Siddhu Fall-2012 paper screenshots). Duplicates across the files were merged and a few answer-key mistakes were corrected against the handouts, with a note shown under the answer.
- **135 subjective flashcards** (Moaaz solved subjectives with handout page references, Junaid current Fall-2022 subjectives, Waqar Siddhu Fall-2012 paper).

Modes:

- **MCQ Practice** – instant feedback after each answer, or press *Show answer*; filter by source, topic and count; "weak & unseen first" ordering; retry only the wrong ones.
- **Mock Exam** – timed paper with no hints, full review at the end.
- **Flashcards** – flip the card, rate *Again* / *Good*; cards you miss come back later in the session and a card becomes *Known* after three good passes.
- **Browse & Search** – every question with its answer, searchable, with bookmarks.

Progress (scores, flashcard boxes, bookmarks, exam date) is saved in the browser's local storage, so it survives closing the file as long as you open it from the same location in the same browser.

This folder is independent of the client site in `site/` and is not part of the GitHub Pages deployment.
